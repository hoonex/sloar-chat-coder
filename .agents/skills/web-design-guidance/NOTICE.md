# Web Design Guidance — source notes

`web-design-guidance` is an independently written Sloar companion. It does not vendor or require the projects below. Its structure was informed by publicly available MIT-licensed agent-design projects reviewed during development:

- `nextlevelbuilder/ui-ux-pro-max-skill` — product-aware design-system recommendation, style/typography/color/anti-pattern categorization, responsive and pre-delivery checks.
- `superdesigndev/superdesign-skill` — persistent repository-aware design-system memory and design-system extraction/setup concepts.
- `educlopez/ui-craft` — surface-oriented design workflows, acceptance bars, rendered self-review, and anti-generic generated-UI thinking.

Their original repositories and licenses remain authoritative for their respective works. No external runtime dependency is introduced by this companion.

Sloar's companion deliberately generalizes these ideas around repository precedence, visual evidence, resilience, and bounded work. Target-repository design rules always take precedence.
