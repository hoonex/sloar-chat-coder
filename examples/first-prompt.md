# First prompt examples

## Minimal

```text
Use Sloar Chat Coder for this repository. Run the first-run capability check before modifying anything, recover the exact repository state, and continue with the task.
```

## Beginner / setup help

```text
I am new to Sloar. Before coding, tell me which capabilities are already available in this chat, which ones are actually required for this task, and whether I need to connect GitHub or any other app. Do not make me configure optional tools. Then use Sloar to recover the repository and work normally.
```

## Korean

```text
Sloar Chat Coder로 이 저장소 작업해. 나는 처음 쓰는 사람이라고 생각하고, 수정 전에 이 채팅에서 실제로 가능한 기능을 먼저 확인해줘. GitHub 플러그인/App 같은 게 정말 필요한 경우에만 세팅 방법을 알려주고, 필요 없으면 바로 정확한 저장소 상태를 복구해서 작업해.
```
